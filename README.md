<h3>Todoist v8896 — Cross-Site Scripting Vulnerability</h3>

<p>
Discovered and reported a Cross-Site Scripting vulnerability affecting Todoist v8896.
</p>

<p>
The issue was related to SVG file upload handling in <code>/api/v1/uploads</code>. Uploaded SVG files were not properly sanitized, allowing embedded JavaScript to execute when the attachment was opened from a task or comment.
</p>
